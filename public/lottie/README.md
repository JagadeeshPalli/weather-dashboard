# Weather Lottie Animations

Drop downloaded JSON files here with these exact filenames.
The app auto-detects them — no code changes needed.

(20 animations, all free)

## How to download from IconScout
1. Go to the pack URL above
2. Click on the individual animation
3. Click "Free Download" → choose "Lottie JSON"
4. Rename the file to match the filename column above
5. Place it in this folder (public/lottie/)

Once all files are here, run `npm run dev` — the scene updates automatically.
